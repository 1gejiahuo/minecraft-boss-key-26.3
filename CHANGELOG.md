# Changelog

## 0.2.0-preview — 2026-10-26

- Extended the Windows application to target Minecraft Java Edition releases from 1.0 onward, including April Fools builds, without game-version-specific code.
- Added foreground Java window matching for builds whose window title does not contain Minecraft.
- Added editable process names, title keywords, and foreground matching in `BossKey.ini`.
- Added a window matching smoke check. Individual game versions and fullscreen modes remain unverified.

## 0.1.0-preview — 2026-10-26

- Added a Fabric client mod for Minecraft Java 26.3.
- Added a standalone Windows background application.
- Added Ctrl+Shift+C global hide/restore and audio handling.
- Added Ctrl+Shift+X safe exit to the standalone application.
- Added editable hotkey configuration for both implementations.
- Confirmed both builds compile. In-game behavior remains unverified.
